# robbe-van-aken

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

See `CLAUDE.md` for the concept, architecture and tunables. In dev mode a small HUD (bottom right) shows the R state, toggles Glyph/Pixels (`G`) and the layout grid overlay (`L`).

All copy lives in `src/data/`.
